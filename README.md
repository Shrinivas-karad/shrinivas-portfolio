# Shrinivas Karad — Ready-to-use portfolio

This is a standalone portfolio website. It does **not** require Node.js, npm, React installation, or a build step.

## Run immediately
1. Extract the ZIP.
2. Double-click `index.html` to open it in your browser.

Google Fonts requires internet access; the page itself and its interactions work without installing dependencies.

## Deploy
Upload `index.html` to any static hosting provider, or use it as the site's entry page. If deploying with Vercel, create a static project with no build command and set the output directory to `.`.

## Included
- Responsive navigation and mobile menu
- Animated hero typing and orbital graphic
- Scroll reveal effects and marquee
- Project category filters
- Graphical project cards and Quick View modal
- Modal closes with Escape or clicking outside
- Skills, education, training, and contact sections
- GitHub links use `Shrinivas-karad`

## Edit your information
Open `index.html` in VS Code and search for the profile text or project data in the `projects` and `skills` arrays near the bottom. Confirm project repository URLs before publishing.
